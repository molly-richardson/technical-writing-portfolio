# Molly Richardson
### Technical Writing & IT Documentation

Technical writing portfolio featuring IT Standard Operating Procedures (SOPs), Knowledge Base (KB) articles, troubleshooting documentation, and enterprise IT processes.

Welcome to my technical writing portfolio.

This repository contains examples of IT documentation focused on clear procedures, troubleshooting, system processes, and enterprise technology environments.

My approach to documentation begins with understanding the bigger picture. I like to understand how systems and processes connect before breaking them down into individual steps. I approach documentation much like putting together a puzzle: understanding how the different components connect, what happens before and after a particular step, and how one part of a system can affect another.

That understanding allows me to create documentation that goes beyond simply listing instructions. My goal is to provide readers with clear procedures, useful context, and an understanding of what to expect throughout a process.
